# landing/src/pages/index.astro — 판단 기록

**정본** = `v2/app/packages/landing/src/pages/index.astro`. 경로는 리포 루트 기준, 명령은 `v2/app`에서.
규칙 원문(`L-*`) → `v2/docs/specs/C3-S6-랜딩.md`. 카피 정본 → `v2/docs/왜-배경지식-설득논거.md`와
`v2/docs/v1-승계원장/13-제품근거-rationale.md`.

등급: `[실행]` 실행 출력 / `[코드]` 코드를 읽었음 / `[대화]` 인용 가능한 사용자 발언 / `[문서]` 문서 하나 / `[미검증]`.

## 판단 1 — 히어로는 "배경지식이 선행 조건"으로 말한다 (사용자 레드펜)

**결정.** 히어로 문장은 다음 한 줄이다. **사용자가 직접 쓴 문장이고 내가 지은 것이 아니다** `[대화]`:

> "AI에게 잘 묻는 일도, 그 답을 판단하는 일도 그 분야의 배경지식에서 시작합니다"

레드펜 원문 `[대화]`: "히어로는 말이 약간 어설퍼. 좀 더 AI를 사용할 때 선행되어야 할 조건으로
강조하는 늬앙스로 다듬어줄래?" → 내가 A·B·C 세 안을 냈고 사용자가 **B를 고른 뒤 직접 고쳐** 위
문장으로 확정했다. 즉 이 문장은 초안이 아니라 확정본이다(L-5가 요구하는 상태).

**같이 지운 것 두 개** `[대화]`:
- **정직 고지** — 내 초안에는 "이 도구가 지식을 대신 갖게 해 주지는 않습니다" 류의 한 줄이 있었다.
  사용자: "그러게 굳이 붙이지 않아도."
- **야구 비유** — 1막을 야구 지식 실험(집단 비교)의 비유로 열었다. 사용자: "와닿지는 않아. 내용
  자체가 어려운건 아니니 비유하지 않아도 쉽게 공감을 얻을거야." 지금 1막은 비유 없이 "그 분야를
  이미 아는 학생들은…"으로 바로 들어간다.

**뒤집으면 깨지는 것.** 되돌리는 자연스러운 이유는 "히어로가 제품을 설명하지 않는다"는 관찰이다
(히어로는 배경지식을 말하고 제품은 다섯 번째 절에 나온다). 되돌려서 히어로를 제품 소개로 바꾸면
**설득논거 §4-6의 "두 축을 섞지 않는다"가 깨진다** `[문서]` — 왜 배경지식인가(1~3막+종합)를 먼저
말하고 나서 왜 배경노트인가(제품 절)로 축을 옮기는 순서가 이 페이지의 구조다. 그리고 위 문장은
사용자 확정본이므로 문구를 고치는 것은 사용자 결정을 뒤집는 것이다.

## 판단 2 — 메타 설명에 "좁히기"를 넣는다 (사용자 지시)

**결정.** `DESCRIPTION`은 아키네이터식 좁히기를 그대로 서술한다.

사용자 원문 `[대화]`: "메타 설명은 아키네이터 좁히기 기획을 잘 나타냈으면 좋겠어. 결국 배경지식
찾는 과정을 귀찮아하는 수요를 타겟팅한 상업 서비스니까."

그래서 두 조각을 넣었다 — ① 직접 찾아 헤매지 않아도 된다(귀찮음이 수요), ② 막연한 한 줄이나
예시에서 시작해 몇 번의 클릭으로 좁혀 간다(기획의 실제 모양). 제품 절에도 같은 좁히기 문장을 넣어
메타 설명과 본문이 같은 말을 하게 했다.

**이 자리가 특별한 이유** `[문서]`: ADR-002가 랜딩의 존재 이유를 "AI 크롤러 인용 채널"로 못박았다.
크롤러가 가장 먼저 읽는 한 문장이 `<meta name="description">`이므로, 여기 들어간 말이 곧 이 제품이
외부에 인용되는 말이 된다. 그래서 여기에 감성 문구를 두지 않고 제품이 실제로 하는 일을 적는다.

**뒤집으면 깨지는 것.** "설명이 너무 기능적이다"는 이유로 감성 문구로 바꾸는 것이 자연스러운
되돌림이다. 그러면 크롤러가 이 제품을 무엇으로 인용할지가 사라진다. 그 손실은 화면에 안 보인다.

## 판단 3 — 랜딩은 앱 스타일시트를 가져오지 않는다. 변수 진입점만 (L-2b)

**결정.** `import "@vock/ui-shared/vars.css"` — 변수만. 요소 스타일과 버튼 모양은 이 파일이 스스로 갖는다.

**실측으로 겪은 결함** `[실행]`. 처음에 `@vock/ui-shared/styles.css`(= `bundle.css`)를 가져왔다.
Playwright로 실제 화면을 재니:
```
main   { flex: 1 1 0%; overflow: hidden auto; min-width: 0; display: flex; flex-direction: column; }
header { display: flex; align-items: center; gap: .625rem; padding: .6875rem .875rem; }
h1, h2 { text-decoration-line: underline; }
```
`main`이 내부 스크롤 판이 되어 **종합·제품 두 절이 화면에서 사라진 것처럼 보였다.** 그런데 여섯 절
전부 실제 높이를 갖고 있었다 `[실행]`(273/234/181/246/134/328px) — **렌더는 되어 있었다.**
이것이 이 결함의 성질이다: 페이지가 깨진 것처럼 안 보이고 "콘텐츠가 적은 페이지"처럼 보인다.

계약이 이미 맞는 말을 하고 있었다 `[문서]` — 인터페이스계약 §7 "landing은 독립(+디자인 토큰만 공유)".
`styles.css`는 디자인 토큰만 담은 파일이 아니었다. 그래서 `vars.css`를 갈라내 진입점을 따로 냈다
(→ `_shadow/…/ui-shared/src/styles/vars.css.md`).

**클래스 접두어 `lp-`도 같은 결함의 다른 얼굴이다** `[실행]`. 접두어 없이 `.hero`·`.lead`·`.summary`를
쓰던 단계에서, 앱의 동명 클래스를 물려받아 `.summary`가 카드 배경과 테두리를 받고 `.hero`가 flex
컨테이너가 됐다. 지금은 변수만 가져오므로 물려받을 것이 없지만, 접두어는 남겼다 — 나중에 누가
앱 스타일시트를 다시 가져오면 그때 다시 겹친다.

**뒤집으면 깨지는 것.** "토큰이랑 앱 스타일 둘 다 쓰면 디자인이 저절로 통일된다"가 되돌리는 이유가
된다. 되돌리면 위 실측이 그대로 재발한다. 지금은 `boundary-check.mjs`가 진입점 이름으로 막으므로
게이트가 먼저 실패한다 `[실행]`(음성 확인함) — 게이트를 우회하려면 `ASSET_ALLOWED`를 고쳐야 하고,
그 파일 주석이 이 이유를 말한다.

## 판단 4 — 한국어 줄바꿈: `word-break: keep-all`과 `<br />` 뒤의 공백

**결정.** `:global(body)`에 `word-break: keep-all` + `overflow-wrap: break-word`. 그리고 히어로
`<br />` **뒤에 줄바꿈을 남긴다.**

**둘 다 좁은 화면 실측에서 나왔다** `[실행]`(360px). ① `<br />`을 `display:none`으로 감췄는데
감춰진 `br`은 공백을 남기지 않아 **"일도그 분야"**로 이어 붙었다. ② 기본 `word-break`에서 한국어가
어절 안쪽에서 끊겨 "그 답/을", "반복됩니/다."로 갈라졌다.

`br` 뒤의 줄바꿈은 HTML에서 공백 한 칸으로 접히므로 그 자리를 메운다. **이 줄바꿈을 지우면 결함이
그대로 돌아온다** — 코드 정리처럼 보이는 편집이 결함을 만드는 자리이므로 파일에 주석으로 적었다.

`break-word`를 함께 둔 이유: `keep-all`만 두면 끊을 수 없는 긴 토큰(URL 등)이 들어올 때 넘친다.
지금 본문에는 그런 토큰이 없으므로 이건 예방이고 실측이 아니다 `[미검증]`.

## 판단 5 — 가격·한도는 문구에 없다 (L-3·L-4·L-4b)

**결정.** 이 페이지에 숫자 가격도 한도 수치도 없다. 유료에 관해 말하지 않는다.

사용자 결정 `[대화]`: "가격과 무료 한도는 추후 정하자. 고정값은 유연성 위반이니, 나중에 환경
변수로 셋업하는게 바람직함." 즉 **정본이 정해진 뒤에도 문구에 적지 않는다**(L-4b). 게이트가
산출물 HTML에서 검사한다 `[실행]`.

**그때 무엇을 근거로 삼았나** — 자기 신고, `[미검증]`.
- **읽은 것** — 설득논거 전문(§0.5·§4 금지선), 제품근거 13장, S6 스펙 전문.
- **안 읽은 것** — 설득논거가 인용한 원 논문. 주장별 근거강도는 그 문서의 표시를 그대로 받았다.
- **브리핑** — 이번 라운드에 현장·주변 두 대. 현장 렌즈가 **내가 만든 이름 충돌**을 잡았다(진입점
  이름을 `./tokens.css`로 냈는데 같은 폴더에 다른 `tokens.css`가 실재). 내 계획에 없던 항목이다.
- **알고도 미룬 것** — 파비콘 없음(`/favicon.ico` 404 `[실행]`), 랜딩 다국어(L-6), 온보딩(L-10),
  광고 슬롯·CMP(L-11). 전부 S6 스펙 §7에 적었다.
- **위치** — S6, 카피 레드펜 반영 커밋.

## 이 노트가 낡는 조건

- **사용자가 카피를 다시 레드펜하면** 판단 1·2의 문장이 바뀐다. 그때도 "내가 지은 문장이 아니다"는
  성질은 유지할 것 — L-5의 요점은 문장의 질이 아니라 **누가 확정했는가**다.
- **랜딩에 상호작용이 필요해지면** L-1이 그 페이지에 한해 다시 판단 대상이 된다(아일랜드는 허용된
  도구지 기본값이 아니다). 그때 `check-landing.mjs`의 "JS 0" 기대도 함께 고쳐야 한다.
- **`ui-shared`가 변수 진입점 이름을 다시 바꾸면** 판단 3의 import 한 줄과 `ASSET_ALLOWED`가 함께
  움직여야 한다. 게이트는 import 문자열만 보므로 이름이 어긋나면 조용히 통과하거나 조용히 막는다.
- **랜딩 다국어를 시작하면** 판단 4의 `keep-all`은 한국어 전제다. 언어별로 다시 판단할 것.
