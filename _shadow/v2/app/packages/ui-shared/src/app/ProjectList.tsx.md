## 판단 1 — `.drawerWrap` 은 이 목록에 쓰면 안 된다. 앱 전체가 클릭을 못 받았다

**무엇이었나** `[코드]`. 이 파일의 `<ul>` 이 `className="drawerWrap"` 이었다. 그 클래스는 v1 의
**플로팅 선택 패널을 화면에 띄우던 오버레이**이고 값이 `position:fixed; inset:0; z-index:45` 다.
한 세트인 `.drawerPanel`·`.drawerHead`·`.drawerDiv` 는 v2 에서 아무도 안 쓴다. 같은 파일 2행 주석은
계승한 클래스로 `.drawerItem` 과 `.sel` 만 적고 있었다 — `.drawerWrap` 은 언급이 없다.

**측정** `[실행]` 2026-08-18. 실제 `bundle.css` 에 실제 DOM 구조를 얹은 목업을 chromium 헤드리스
1280x860 에서 렌더하고 `document.elementFromPoint` 를 다섯 지점에 쐈다.

```
입력창 → UL.drawerWrap      예시 칩 → UL.drawerWrap
재진입 카드 → UL.drawerWrap   전송 버튼 → UL.drawerWrap
사이드바 세션 항목 → UL.drawerWrap
```

**로그인한 사용자는 넓은 화면에서 아무것도 클릭할 수 없었다.** 화면은 정상으로 보이고 모든 클릭이
투명한 목록에 먹힌다. `.plist` 로 교체한 뒤 같은 다섯 좌표가 각자의 요소를 돌려준다 `[실행]`.

**재현 명령은 리포에 없다** — 스크래치패드의 일회성 하네스였다. 이것이 이 항목의 약점이다.

**왜 지금까지 안 잡혔나** `[미검증]`, 정황만 있다. 프로젝트 목록은 로그인해야 렌더되고
(`off` 일 때 조기 반환), 로컬 로그인은 Google OAuth 설정이 필요하다. 게이트는 전부 node 스크립트라
브라우저를 안 띄운다. C5-S2 의 남은 항목이 문자 그대로 "좁은 화면 실측 — 브라우저에서만 판정"이다.

**빈 목록이 조기 반환이 아니라는 점이 범위를 넓혔다** `[코드]`. `items.length === 0` 은 인라인
조건부라, **프로젝트가 0개여도 로그인만 하면 이 `<ul>` 이 렌더됐다.**

**뒤집으면 깨지는 것.** `.plist` 가 `.history` 와 선언이 거의 같아 보여 "중복이니 `.history` 로
합치자"는 정리가 나올 수 있다. 그러면 세션 목록의 간격을 손볼 때 프로젝트 목록이 따라 움직인다.
더 위험한 것은 v1 클래스로 되돌리는 쪽이다 — 이름이 그럴듯해서 되돌리기 쉽고, 되돌리면 증상이
"앱이 안 눌린다"인데 원인이 CSS 한 줄이라 찾는 데 오래 걸린다. **그래서 이유를 `shell.css` 의
`.plist` 규칙 주석에도 남겼다.**

## 이 구멍이 구조적이라는 것

관계 인덱스는 CSS 클래스를 **정의로 나열만 하고 `readers=` 를 안 붙인다** `[코드]`. 그 표기는
export 된 심볼에만 있다. 따라서 죽은 CSS 도, 정의 없는 클래스도 어떤 게이트에도 안 걸린다.
같은 구멍이 낳은 것이 D-11(`.sbSearch` 는 소비처 둘인데 **정의가 없다**)과 D-12(약 70개 죽은 클래스)다.

## 그때 무엇을 근거로 삼았나 — 자기 신고, `[미검증]`

- **읽은 것** — 이 파일 전문, `tokens.css` 의 `.drawer*` 블록 전량, `bundle.css` 의 import 순서,
  `shell.css` 전체(컨테이닝 블록을 만드는 속성이 없음을 확인).
- **브리핑** — S3a 비판 라운드의 한 대가 이 건을 "정적으로 확정 가능, 렌더 불필요"로 판정했다.
  **그 판정이 맞았고 내가 과하게 유보했다** — 나는 "실측 필요"로 인덱스에 적었었다.
- **실행으로 확인한 것** — 위 elementFromPoint 5점, 교체 전후 스크린샷 2장, 게이트 exit 0.
- **알고도 미룬 것** — D-11 수정, CSS 클래스 소비자 게이트 신설.
- **위치** — C5-S3 구현 완료 후 실측 단계, 사용자가 "고쳐"로 범위를 열어준 뒤.

## 이 노트가 낡는 조건

- **CSS 클래스 소비자 게이트가 생기면** 이 결함 유형이 기계로 잡히므로 이 노트의 "구조적 구멍"
  절이 낡는다. 그 게이트는 인덱스의 D 목록을 오라클로 쓸 수 있다.
- **`.drawerPanel` 세트를 정리하면** `.drawerWrap` 도 함께 사라져 되돌릴 대상 자체가 없어진다.
