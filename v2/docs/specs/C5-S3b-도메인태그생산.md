# C5 S3b 스펙 — domain_tags 생산자 (SRS FR-312·Q-02, SoT §2-3에서 파생)

> 앞 = [C5-S3](C5-S3-재방문카드.md). 뒤 = C5-S4 마인드맵(FR-312) — 이 슬라이스가 그 선행 조건이다.
> 규칙: G-1~G-5 (5건)

## 0. 범위

**포함.** 담기 시점에 서버가 `domain_tags`를 파생시킨다 · 기존 자산 백필 · 요청 바디 의존 제거.
**제외.** 마인드맵 본체 · 교차분야 임계값 실측(재료가 쌓인 뒤에 한다) · 어휘별 세분 태그.

## 1. 왜 지금인가

`assets.domain_tags`는 스키마에도 타입에도 있는데 **모든 행이 비어 있다.** 서버가 요청 바디에서
그대로 받고, 그 값을 보내는 클라이언트 코드가 없기 때문이다. 담기를 호출하는 자리는 저장소에
하나뿐이고 그 값을 넘기지 않는다.

결과가 둘이다. Q-02에서 확정한 **교차분야 연결 레이어에 재료가 없고**, 이미 담긴 자산은 행만
봐서는 태그를 복구할 수 없어 어휘 본문에서 다시 만들어야 하는 백필이 된다.

**미룰수록 비싸진다.** 백필 대상이 시간에 비례해 늘어난다.

## 2. 동작 규칙

| # | 규칙 | 근거 |
|---|---|---|
| G-1 | `domain_tags`는 **서버가 세션의 `area`에서 파생시킨다.** 담기 요청 바디의 값을 읽지 않는다 | 권한과 판정은 요청 입력에서 오지 않는다. SoT가 FR-706 dedup에 대해 같은 것을 이미 명시했다 — "서버 책임이다 … 클라 전달 의존 금지". `area`는 분류 단계 출력에서 파생돼 세션에 영구 보존되므로 서버가 이미 알고 있다 |
| G-2 | 태그 단위는 **세션의 분야 하나**다. 어휘마다 다른 태그를 뽑지 않는다 | 교차분야 연결의 신호는 "같은 어휘가 서로 다른 분야 세션에서 담겼다"는 사실 자체다. 어휘별 태그는 LLM 단계를 하나 더 요구하는데 그 비용으로 사는 것이 이 목적에는 없다 |
| G-3 | `area`가 없으면 빈 배열이다. 주제(`topic`)로 대체하지 않는다 | `topic`은 사용자가 적은 자유 문장이라 분야가 아니다. 같은 분야를 다르게 적은 두 세션이 서로 다른 태그를 갖게 되어 교차 연결이 오히려 끊긴다 |
| G-4 | `KeepBody`에서 `domain_tags`를 **없앤다** | 남겨 두면 서버가 안 읽는 필드를 클라이언트가 보낼 수 있고, 다음 사람이 그 필드를 채우면 조용히 무시된다. 안 읽을 값은 받지 않는다 |
| G-5 | 기존 자산은 **마이그레이션으로 백필한다.** `assets`를 `sessions`에 조인해 `area`를 넣되, 이미 채워진 행은 건드리지 않는다 | 재료 없이는 임계값 실측이 불가능하고, 실측 없이는 S4가 연결선을 몇 개 그을지 정할 수 없다 |

## 3. 계약 변경

| 대상 | 내용 |
|---|---|
| `KeepBody`(클라 `api/port.ts`) | `domain_tags` 제거 |
| SoT §3-3 `PUT /sessions/:id/keep` | 서버가 `domain_tags`를 파생시킨다는 서술 추가 |
| 마이그레이션 | `0004_domain_tags_backfill.sql` 신설 |

**타입 변경은 없다.** `AssetTerm.domain_tags`도 `assets.domain_tags`도 그대로다 — 채우는 주체만 바뀐다.

## 4. 파일

| 파일 | 책임 |
|---|---|
| `adapters/http-app/src/routes/crud-routes.ts` | 담기 핸들러에서 세션을 조회해 `area`로 채운다 |
| `adapters/persistence/migrations/0004_domain_tags_backfill.sql` | 백필 |
| `ui-shared/src/api/port.ts` | `KeepBody`에서 필드 제거 |
| `v2/docs/인터페이스계약-v2.md` | §3-3 서술 |

## 5. 게이트

`gate-db`가 이 슬라이스의 실검사다 — 담기 왕복에서 태그가 채워지는지는 PG 없이 확인되지 않는다.

## 6. 검증

| 케이스 | 기대 |
|---|---|
| `area`가 있는 세션에서 담기 | 자산의 `domain_tags`가 `[area]` |
| `area`가 `null`인 세션에서 담기 | 빈 배열(음성) |
| 요청 바디에 `domain_tags`를 실어 보냄 | **무시된다**(음성, G-1) |
| 백필 후 기존 자산 | `area`가 있던 세션의 자산만 채워진다 |
| 백필 재실행 | 이미 채워진 행이 안 바뀐다(멱등) |

## 7. 열린 항목

- **교차분야 임계값** — 태그 몇 개가 겹쳐야 연결선을 긋는가. 재료가 쌓인 뒤 실측한다(SoT `:289` 미측정 항목)
- **어휘별 세분 태그** — G-2가 미룬 것. 세션 분야만으로 부족하다는 근거가 나오면 그때 연다
