**C5 진행 중** — S1(조회·저장 축)·S2(종착 화면) 완료. **S3(재방문 능동 카드)는 요구사항·계약을 세운 뒤 보류 중**이고, 선행으로 **S3a(UI/UX 인덱스)**를 끼웠다 — 화면에 무엇이 이미 있는지가 한눈에 안 잡혀 설계가 반복해서 막혔기 때문이다(사유는 `C5-S3-재방문카드.md` §0). 그 뒤가 **S4 마인드맵(FR-312)**, 결제·수익 재설계, 실 AWS 배포 핸즈온이다.

> **폐기 축 주의.** 지식 상태 태깅(알아/몰라/적용모름)과 `knowledge` 테이블, `PrimerDoc`의 `known_terms`/`unknown_terms` 분리는 **C5-S1에서 전부 폐기**됐다(SRS §6.4, 폐기 ID FR-501·FR-502). 아래 표의 C2.1·C3-S4b 행은 **당시 기준으로 완료된 기록**이며 현행 규칙이 아니다 — 각 문서 머리에 폐기 표시가 붙어 있다.
