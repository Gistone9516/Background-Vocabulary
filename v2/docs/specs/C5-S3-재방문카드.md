# C5 S3 스펙 — 재방문 능동 카드 (SRS FR-707·FR-608, SoT §2-3·§3-3에서 파생)

> 앞 = [C5-S1](C5-S1-조회저장과상세영속.md) · [C5-S2](C5-S2-종착화면.md). 뒤 = C5-S4 마인드맵(FR-312).
> 규칙: **미확정** — S3a(UI/UX 인덱스) 완료 뒤에 확정한다. 접두문자는 `V`를 예약했다(`A·D·DS~DS5·E·K·L·P·R·S·T` 사용 중).
> **상태: 보류(2026-08-17).** 요구사항과 계약은 커밋됐고 스펙 본문만 대기한다.

## 0. 왜 보류인가

설계 도중 같은 종류의 병목이 반복해서 나왔다. 화면에 이미 무엇이 있는지를 그때그때 코드를 파서 알아냈고, 그 과정에서 판단이 여러 번 뒤집혔다. 비판 패널 6대를 두 라운드 돌린 결과 발견의 상당수가 결함이 아니라 **이미 있는 것을 몰라서 생긴 오해**였다.

실제로 뒤집힌 것들이다. 진입 화면 상단에 아무것도 못 얹는다고 판단했으나 조건부 요소가 이미 거기 있었다. 접근성 관례가 없다고 판단했으나 `aria-label` 13곳을 포함해 이미 있었다. 담은 어휘 화면이 새로 필요하다고 판단했으나 `Journey`에 `kept`가 이미 있었다. 확장 슬롯을 새로 설계하려 했으나 `PrimerScreen`의 `mapPanel`이 이미 관례였다.

그래서 **S3a를 앞에 세운다.** 화면 요소·슬롯·불변식·상태 관례를 한 장에서 찾을 수 있는 UI/UX 인덱스를 만들고, 그 위에서 이 스펙을 쓴다.

## 2. 도착 화면 — 왜 서버 복원인가

`TermsScreen`은 담은 어휘 링크를 담은 개수가 0보다 클 때만 그린다. 그리고 세션 재개 경로는 생성 목록만 복원하고 담기 상태는 건드리지 않는다. 담기는 화면 상태로만 유지되기 때문이다.

이어붙이면, 문구만 낮춰 세션으로 보내는 안은 **담아둔 것에 닿을 통로를 화면에서 없앤다.** 카드가 개수를 보여주고 눌렀는데 그 어휘에 갈 길이 없다. 데이터는 서버에 있고 사용자만 못 본다.

비판 패널의 다수는 문구를 낮추는 쪽이었으나, 그 다수 안에서 위 사실이 나왔고 결론이 뒤집혔다. 같은 모델이 다수를 이룬 것은 근거가 아니다.

범위는 셋이다. `Journey`에 `kept`가 이미 있어 새 화면이 아니고, `assets`에 `UNIQUE(user_id, session_id, term_norm)`이 있어 스키마 변경도 없다.

- 자산 레포지토리에 세션 스코프 목록 하나
- 그 라우트 하나 (`GET /sessions/:id/viewed`를 그대로 베낀다)
- 세션 재개 시 담기 상태를 채우는 한 곳

**함정:** 기존 재개 경로가 `lastCtx`를 채우지 않는다. 담기 복원 경로에서 같은 누락을 반복하면 프라이머로 넘어갈 때 주제와 조건이 빈 채로 간다.

## 3. 아직 안 정한 것

- **트랙 좌우** — 카드가 왼쪽 트랙인지 오른쪽인지
- **좁은 화면 접힘 순서** — 트랙이 한 줄로 접힐 때 카드가 위인지 아래인지
- **스코프 표시** — 진입 화면에 현재 프로젝트 스코프를 어떻게 보이는가. 지금 진입 화면은 프로젝트 이름을 받지 않는다
- **FR-608의 귀환 경로** — 프라이머 화면에 이미 담은 어휘 링크가 있다. 그것을 재사용할지 종료 확인 옆에 별도 CTA를 둘지
- **문구** — 분야가 없을 때와 담은 개수가 0일 때 각각

## 4. 인덱스가 서면 규칙으로 옮길 것

비판 패널이 남긴 채택 목록이다. S3a 완료 뒤 `V-n` 번호를 붙인다.

- 카드 자리는 예약된 높이로만 허용한다
- 카드는 주입 슬롯으로 받는다 (`mapPanel`과 동형)
- 재조회는 진입 화면으로 전이할 때, 선택된 프로젝트, 로그인 여부 셋에만 의존한다. **v1이 같은 자리에서 실제로 겪은 사고다** — 홈 복귀 시 다시 부르지 않아 카드가 사라졌고, 복귀 시 명시적으로 다시 부르는 것으로 고쳤다
- 카드는 네이티브 상호작용 요소로 만들고 탭 순서를 명시한다. `autoFocus` 금지
- 분야는 문장에 섞지 않고 맨 라벨로 쓴다 (받침 조사 판정 유틸이 저장소에 없다)
- 새 문구는 `AUTHORED` 사전에 손으로 추가한다
- 담기 복원 시 `lastCtx`를 함께 채운다
- 넓은 화면에서 카드와 목록 첫 행이 같은 세션을 상시 보인다. 시각 위계를 정한다

## 5. 쓰지 않기로 한 것

| 버린 것 | 이유 |
|---|---|
| `aria-live` 신설 | 저장소 전체에 없는 관례를 카드에만 처음 만들면 정당화 안 되는 예외가 된다. 전 화면 단위 결정 |
| `EditSheet` 포커스 트랩 수리 | 이 슬라이스는 모달을 추가하지 않는다. 남의 부채다 |
| 데스크톱 단축키 충돌 조사 | `autoFocus` 금지 한 줄로 닫힌다 |
| 세션 완료·삭제·복원 직후 재조회 | 그 시점에 카드가 화면에 없어 다음 진입에서 해소된다 |
| 목록 행에 담은 개수를 노출해 밀도를 맞추기 | 방금 세운 정본 분리와 충돌한다 |

## 6. v1의 지위

v1은 과거 기획이며 **규칙이 아니다**(사용자 지시 2026-08-17). 승계원장의 등급 체계가 같은 것을 이미 말하고 있다 — `_참고/`는 직접 입력 금지다. d-2가 담긴 `12-평가비판-d.md`가 그 등급이므로, 이 슬라이스의 근거는 사용자 확정이지 승계원장이 아니다.

다만 v1이 **같은 자리에서 실제로 밟은 지뢰의 기록**은 등급과 무관하게 값이 있다. 규칙으로 따르는 것이 아니라 재현을 피하는 용도다.

- 입력창 아래에 개수가 변하는 목록을 흐름째 쌓으면 입력창이 표류한다. v1은 그 목록을 흐름에서 빼내 해결했다
- 홈 복귀 시 재조회를 명시하지 않으면 카드가 사라진다
- 스코프 홈은 별도 페이지가 아니라 메인 레이아웃 재사용이 맞다. v1은 별도 페이지로 만들었다가 되돌렸다
